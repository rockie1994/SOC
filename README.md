Welcome to my journey of building Security Operations Center (SOC) detection tools from scratch!

The Goal:

To deeply understand how attackers operate and how defenders catch them, I am building a small, functional detection tool every single day. By the end of this challenge, this repository will contain a massive library of scripts covering endpoint detection, network analysis, threat intelligence, and cloud security.

The Tech Stack:

Language: Python 3 (Primary), Bash, PowerShell
Environment: VS Code
Focus Areas: Log Parsing, Threshold Alerting, Network Traffic Analysis, OSINT

Repository Structure:

Each folder contains the code, sample data (logs), and a specific README.md detailing how that day's tool works.

How to Use This Repo:

Feel free to explore the folders. Most scripts are standalone Python files that can be run directly in your terminal (e.g., python detector.py). Sample log files are provided in each folder so you can test the scripts safely without needing a live server.
